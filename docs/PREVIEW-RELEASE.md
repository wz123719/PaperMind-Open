# PaperMind v0.1.0 · Windows 预览版

这是 PaperMind 的首个对外试用版本。下载源码 ZIP，按 README 安装依赖和启动；无需开通模型 API 就能先体验 PDF 导入、基础解析、阅读与原文定位。

- PDF 论文库：本地上传、arXiv 导入、结构解析、搜索和高亮定位。
- 综合精读：前置知识、架构与算法、实验分析、带原文引用的综合报告。
- 学术翻译：原文、译文和双语阅读；按需配置自己的模型服务。
- 知识笔记：按论文模板生成 Markdown，支持编辑、审核和发布到 Obsidian。
- Windows 快速启动：安装后运行 `start.ps1`。

需要提前知道：下载包只包含源码；需要本机 Python、Node.js 和 pnpm。基础安装不包含 Docling 和 PyTorch，进阶解析可按文档追加依赖和模型。综合精读与 AI 翻译需配置模型服务，解析和模型输出不能代替人工核对。
