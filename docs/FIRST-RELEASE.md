# 首次公开发布

计划版本：`v0.1.0`，Windows 源码预览。发布说明草稿见 [PREVIEW-RELEASE.md](PREVIEW-RELEASE.md)。

1. 确认可授予源码许可证的主体和许可方案。当前运行时直接使用 PyMuPDF，需考虑其 AGPL 或商业许可；见 [第三方组件](../THIRD_PARTY.md)。
2. 确认 Git 历史和公开素材的范围。本版截图来自合成 PDF 和本地测试模型替身，没有使用日常论文库。源码 ZIP 不包含依赖、权重、PDF 或本地配置。
3. 在干净的 Windows 源码目录执行 `setup.ps1` 与 `start.ps1`；验证导入、原生解析、阅读、笔记保存和测试 Vault 导出。使用合成凭据或测试模型服务验证流程；真实模型质量需单独评估。
4. 在 GitHub 确认 Windows 检查通过后，可用版本标签 `v0.1.0` 创建 Release。检查 Release 的源码 ZIP 与说明，再确认仓库公开并发布。
5. 请一位朋友从 Release ZIP 独立走一次快速开始，记录安装时间和遇到的阻碍。

本地验证：在不包含 `.env`、日常数据库和模型权重的 Windows 源码副本完成基础依赖安装、前端构建、启动与关闭检查；`pip check` 通过，316 项后端测试通过。隔离浏览器使用合成论文和本地模型替身走通精读、跳转原文和保存笔记，Vault 文件导出由后端集成测试验证。Docling、公式模型和真实模型质量仍需按各自路径另行验收。

发布历史：当前源码中的本机绝对路径已整理；既有 Git 提交仍包含旧开发路径。如不希望一起公开，可用当前源码创建一个没有旧历史的公开仓库，保留现有仓库作开发档案。
